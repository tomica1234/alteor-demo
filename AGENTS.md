# Project Instructions

When the user supplies LP design images, use the `image-lp-from-reference` skill.

Important:
- The user will generate the images separately.
- Do not generate new images unless explicitly requested.
- Treat supplied images as the design source of truth.
- Analyze the images first, then implement.
- Build the landing page as real HTML/CSS/React components.
- Run the build command and fix errors.

Default LP stack:
- React + TypeScript + Vite
- Plain CSS or CSS modules
- Responsive design
- Japanese copy when the product is Japanese
